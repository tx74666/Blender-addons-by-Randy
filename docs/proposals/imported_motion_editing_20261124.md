# 匯入動畫在 X 的預覽、FK 編輯與 IK 準備

2026-11-24 · Character Designer 互動與實作設計草案。依據 0.77.234 程式及 11 月 19 日的 In Air 作業。

## 動畫師看到的操作

點片名就在目前的 X 角色上看動作。已有編輯稿時，片名直接開啟這個角色上次編輯的版本，包括舊版已準備好的控制器 Action。普通 FK 編輯可轉動關節和插關鍵幀。需要把手掌或腳掌固定在空間某處時，再加入 IK 目標與極向控制器。FK 和 IK 都在 X 的角色上操作。

| 動作列狀態 | 點片名 | 右側唯一的操作或狀態 |
|---|---|---|
| 首次開啟 | 在 X 預覽匯入片段，可拖時間軸 | `Edit FK` 建立可編輯副本 |
| 已有 FK 稿 | 開啟 FK 稿 | 在選取的手或腳上使用現有 FK／IK 切換入口，預設匹配當前幀；要轉一段時另選範圍 |
| 正在準備 IK | 仍可預覽或繼續編輯 FK | 顯示部位和進度；面板頂部提供取消 |
| 已有 IK 稿或混合稿 | 開啟最近編輯的稿 | 顯示目前肢體的模式，可在當前幀切回 FK，也可為其他肢體加入 IK |

保留 `All / Pinned` 和固定圖釘。有可批次準備的動作時，頂部提供 `Prepare All Missing IK (N)`，明確表示替目前角色的全部缺少片段準備全身 IK，包括未固定的片段。批次只補缺項，遇到已有局部編輯的稿時保留該稿並列出需另外處理的項目。成功後取消高亮。`Open Source Motion` 放在進階區，作為主動前往來源場景的入口。保留 Unity 來源骨架與網格供匯入和校驗使用。

## 同一隻腳交替用 FK 和 IK 打鍵

動畫師可以用 IK 手柄擺一個姿勢，再把結果記成 FK。接收 FK 鍵前，讀取**拖動後**的可見腿部與腳掌姿勢並匹配 FK，讓前後的 FK 鍵按原插值連接。此操作適合把空中的腳抬高一次；對需要持續接觸地面的腳，採用有起訖的 IK 區間。

要保留真正的 IK 編輯時，每條肢體各自記模式鍵。新增的模式鍵採階梯插值；姿勢與軌跡按各自的動畫曲線播放。切入時先匹配接手的控制器，再把模式與必要通道一併記錄。以右腳為例，第 10 幀 FK，第 20 幀切 IK，第 30 幀切回 FK；若區間內沒有其他模式鍵，第 20–29 幀由 IK 接手。若只要第 20 幀由 IK 驅動，回到 FK 的邊界在第 21 幀。回切時由當下的可見姿勢接手；若要恢復原稿第 21 幀的指定姿勢，則明確保留那個姿勢。模式切換能銜接姿勢，速度連續與腳底接觸仍要看相鄰幀的軌跡。

自動鍵開啟時沿用現有的配對鍵寫入；手動工作流應支援「切換、拖動、打鍵」一次記全。暫存切換前的模式與銜接姿勢，提交時使用作者調整後的控制器值；僅在該肢體與當前幀有待記錄切換時啟用此行為，保留自訂 Keying Set 的適用範圍。若普通插鍵入口無法完整記錄，提供明確的「記錄姿勢與模式」操作和待記錄提示。預先已有模式鍵時，以實際的下一個模式鍵為邊界。跨越作者手打的模式鍵或漸變權重時顯示衝突，讓作者選範圍。

原型回放用上述 10、20、30 幀案例，另測相鄰幀回切、只用 IK 擺一次後存 FK、以及另一隻腳同時為 FK。對照前後幀、切換附近的子幀並重開回讀，核對腳踝、膝向、模式與原有鍵；在切換前後姿勢一致之外，也檢查是否有可見的速度突變。

## 為什麼把 FK 放在前面

In Air 的輸出是第 1–65 幀，24 fps。11 月 19 日的作業成功產生控制器 Action。程序紀錄的經過時間是 82 分 37 秒。背景階段內，反推控制器花 8 分 09 秒，首次控制器回放檢查花 23 分 46 秒，精簡關鍵幀後的回放檢查花 32 分 32 秒。這次總共解了 193 個時間點，兩輪各查 769 個位置，沒有觸發自適應重算。完整流程還有載入、骨架映射、最後比對與回寫。這些階段耗時已包含在各自的上層計時裡。

這套 rig 的四肢 FK 直接使用原骨，另有獨立 IK 目標及極向控制器。腰、脊椎、腳趾等部位有各自的控制器映射；Unity 與 X 也可能有不同 Rest、比例和根位移。現有映射器已能算出目標 FK 姿勢，之後才建立整段 IK。優先試做重用這段映射的單幀入口。舊流程光是生成整段 FK 參考及檢查映射就各花了約 82 秒和 102 秒。

## 實作順序

1. **先做一支能看的片。** 在 X 的隔離副本，把來源 Action 和 slot、兩端骨架、Rest 校準、比例、幀率與肢體模式配對。預覽先算使用者要看的當前幀，再準備附近幀；快速拖曳或換片時丟棄過期請求。用可撤回的預覽狀態顯示在 X 角色上，離開時還原原 Action、slot、模式和動畫綁定。如果映射器不能安全呈現此骨架，保留當前畫面並指出缺少的映射。單獨量首次可見和首次可順播的時間。
2. **FK 稿可單獨交付。** 重用已計算的目標姿勢，依來源時間和校準結果寫成屬於 X 角色的獨立 Action。把必要的 FK/IK 狀態、軀幹與腳趾控制器通道寫進稿件，核對原生播放、插幀和重開。保存使用者改過的 Action 身分與 slot。把 `FK 可編輯`、`哪些肢體已有 IK`、`全身 IK 就緒` 分別記錄。
3. **同一份稿按肢體切換 FK／IK。** 先用一條腿驗證雙向切換。FK → IK 讀取 X 角色已評估的腳踝位置和腳掌朝向，以綁定時的偏移換算成手柄變換。用膝蓋偏離髖踝連線的方向定彎曲面；接近伸直時沿用上一個有效方向，首幀採用骨架校準方向。沿用 rig 的 pole angle、控制器父空間與足部翻滾設定。IK → FK 先讀取畫面上實際解算出的大腿、小腿與腳掌姿勢，匹配 FK 後切換影響權重。重用現有單肢匹配與 Action 寫入規則。當前幀切換遵守原有插幀／Auto Key 行為；整段和選區轉換才建立時間軌跡，包含起訖邊界銜接與其他肢體保留。先對位並檢查末端、膝肘和方向連續性，超差才做局部修正。若共享約束使該肢體無法獨立切換，保留原姿勢並指出原因。
4. **回用結果。** 預覽快取以來源 Action/slot 內容、目標骨架與 Rest 校準、幀率、映射版本等會改變姿勢的輸入辨識。同一段的源姿勢可供多輪比對重用；不同輸出候選仍要各自播放驗證。背景作業只在輸入仍相符時發布。改稿、切片、取消或失敗時保留已有編輯；舊版已準備稿照常可開。

## 原型驗收

| 在 X 副本從實際操作開始計時 | 建議目標 | 量到何時 |
|---|---:|---|
| 第一次點 In Air | 1–2 秒 | X 角色顯示所選幀的正確姿勢。另記第一次連續順播 |
| 第一次開可編輯的 FK 稿 | 理想 30 秒內，首版 60 秒內 | 實際能轉動指定 FK 骨、插幀並回放 |
| 再開已有的 FK 或 IK 稿 | 1–2 秒 | 恢復正確的稿和 slot，時間軸可操作 |
| 已在 X 上的動作，當前幀切一隻腳 FK ↔ IK | 理想 0.2 秒內，可接受上限 1 秒 | 兩個方向各量從點擊至畫面可拖動，檢查切換瞬間的腳踝、腳掌朝向與膝彎 |
| 為選區／全片產生 IK 軌跡 | 原型實測後訂 | 所選部位能用 IK 編輯。分列完整經過時間及前景最長停頓 |

上述為設計目標。30／60 秒衡量首次能用 FK 編輯；整段全身 IK 有獨立的測試項，仍需實測。先用 In Air 看空中姿勢與循環接縫，用 Walk Forward 看根位移和著地腳滑，再用 Wall Jump 看快速轉向與肢體彎曲方向。對相同來源、Rest 與比例，將 X 的原生回放與校準後的來源姿勢比對。沿用目前日常模式的世界位置 3 mm、旋轉 1° 與現有縮放檢查作為第一輪參考。另檢查髮裙來源通道或 X 既有次級動畫的相容性，遇到未支援資料須指出。開發驗收可離線密查完整輸出；日常流程先核對來源關鍵時間、區間中點、接觸及循環邊界，有超差的區段再加密。使用者實際看到的時間須包括前置工作、資料發布與恢復互動。

首版原型同時驗證「在 X 看正確姿勢」「FK 稿能改、能重開」及「同一幀右腳 FK → IK → FK，姿勢銜接且其餘肢體仍可用 FK」。再測有著地動作的選區與整段 IK。既有 In Air 的結果可作對照；該次原始輸入快照已在成功後清除，重測須標明使用的場景、來源、骨架與版本。
