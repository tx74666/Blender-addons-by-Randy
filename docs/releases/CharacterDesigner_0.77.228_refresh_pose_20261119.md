# Character Designer 0.77.228 — preserve the current foot pose on refresh

On 2026-11-19, the X scene reproduced a downward foot rotation on Refresh Add-on after an Alt+R reset. With the same Action, slot and frame, the old add-on's unregister path restored the right foot-roll control from zero to about −43.2° and discarded the active limb reset. The largest shoe vertex coordinate change in the isolated 0.77.227 reproduction was 0.091934 in mesh-local Blender units.

Refresh now hands the current limb reset and its keyed and unkeyed edits to the incoming module. The next frame or Action change continues to use the ordinary animation rules. Refresh waits for a binding transaction or file-read callback already in progress. If the replacement fails to register, the previous module can take back the current pose. This changes the refresh callback and the limb-state transfer in two runtime files.
