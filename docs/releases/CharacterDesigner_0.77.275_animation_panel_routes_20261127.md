# Character Designer 0.77.275 · 动画工具入口

- **Miscellaneous → Unity Export** 用三个并排选项切换 Objects、Animations 和 Materials。Animations 提供已有的 Unity 发送及 FBX 导出入口。
- **Animation → Import Animations** 保留 Unity 动作列表连接、同步和单动作导入。
- **Miscellaneous → Equipment** 提供 Upper-Body Composition，与装备附着和握把设置放在一起。
- **Animation → Editing & Recovery → Edit on Source Rig** 在来源场景打开选中导入动作的可编辑副本。Convert to IK 和极点对齐仍在 Motion Tools。
