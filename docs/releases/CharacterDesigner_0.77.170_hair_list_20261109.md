# Character Designer 0.77.170 — Hair list after X2 migration

The Hair list can open on the migrated X scene when CoshaRig is active in Pose Mode. Each compact row shows the strand name, bone count, category, and side. Click the row to select its bones, Ctrl-click to toggle a row, or Shift-click to select a range.

The migrated file retains its native Hair binding and saved strand registry. It also retains the Hair and Main session records, with both managed reference groups trimmed during the transfer. In that specific case, the list independently checks the local mesh and rig, the saved strand identities and segmentation, Rest data, and mirror pairing. A match enables selection only. Apply, physics, and other managed edits still require their full history checks. The fallback leaves trimmed references absent.

Custom Vertex Groups and Parts also drop the per-row lock column. Their menus show **Unlock All** only when the corresponding list contains an existing lock, so older locked entries can still be unlocked explicitly.

A private Blender 5.2 probe with the four candidate Hair modules populated 21 rows for 32 physical chains (Front 10 × 3 bones, Side 8 × 4, Back 14 × 8). Single, Ctrl, and Shift selection returned the expected bone names. The strict check continued to refuse managed access, and the probe verified exact Hair source properties and saved file metadata.
