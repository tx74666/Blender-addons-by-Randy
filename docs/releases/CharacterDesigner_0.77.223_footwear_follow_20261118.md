# Character Designer 0.77.223 · 脚底圈与后跟圆箭头

脚底圈根据左右鞋外底的长宽、中心和最低点分别定位，轮廓周围留出窄边。整脚抬起或转向时，脚底圈贴着鞋底，后跟圆箭头随同转向。圆箭头的旋转轴穿过自身圆心。单独踮脚或弯趾时，脚底圈保持在该姿势的支撑平面。脚尖控制器的设计留待单独处理。

已有后跟控制器的角色可在 **Body Setup & Recovery** 选择对应腿并使用 **Fit Foot Controls**。高级选项可以指定鞋网格并重新拟合。校准保留鞋子、骨骼动画和原有 IK 输入。仅骨骼的角色沿用已有轮廓。

Blender 副本测试覆盖左右脚着地、抬脚、转向、弯趾、踮脚、Alt+R/G、Direct/Stable 混合和新建/移除。六个姿势中脚底角度最大误差低于 0.002°，局部抬跟和弯趾的轮廓位移为 0。重开副本时，Blender 会重新计算既有动作与绑定输入，已按载入后实际姿势核对脚底轮廓。旧测试使用重新求值前后的不同姿势比较绝对坐标，相关失败记录保留在验收目录。
