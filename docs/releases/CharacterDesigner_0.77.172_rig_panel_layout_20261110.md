# Character Designer 0.77.172 — Grouped Rig Setup

Approved, 2026-11-10. Rig Setup now contains the Body, Hair and Skirt category buttons and the tools belonging to the selected category. Folding Rig Setup hides its categories and child tools together. Character & Bone Mapping provides shared rig and bone-role fields; Bone Display remains available on Rig and Weight pages.

The tool names describe their purpose:

- **Body Controls** contains the existing generation, calibration and IK/FK controls. Its detailed options read **Body Setup & Recovery**.
- **Back & Chest** bends the back and moves the chest; **Finger Controls** contains the existing finger tools.
- **Forearm Twist Correction** provides experimental local forearm-shape correction. Its existing angle and add-on limits still apply.
- **Curve Chain Controls** bends a selected continuous bone chain using a curve, with its existing Body-page availability.
- **Hair Strands & Binding** contains strand and binding tools; **Hair Motion Settings** contains existing hair-motion options.
- **Skirt Controls & Binding** contains skirt setup and attachment tools.

Forearm and Curve Chain retain their closed defaults. Category/tool polls, property defaults, operator entry points, session rules and backend logic are unchanged from171. The purposes added to Back & Chest, Forearm Twist Correction and Curve Chain Controls are labels. The existing Rig Setup panel registers immediately after the main panel, before its children; panel identifiers stay stable.
