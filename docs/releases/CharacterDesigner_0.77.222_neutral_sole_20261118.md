# Character Designer 0.77.222 · 脚底 IK 复位

`CTRL_foot_IK.L/R` 的中立轮廓采用原来的脚底校准。以前如果在腿已摆出姿势时升级，当前脚踝的倾角会进入显示偏移，旋转和位移清零后鞋底轮廓仍然倾斜。

在 Pose Mode 选中脚底控制器，Alt R 清旋转，Alt G 清位移。抬脚跟或弯脚趾时，脚底圈保持原位。直接操作脚底圈仍可移动和旋转整只脚。

本次用相同绑定标识、骨骼静置矩阵、轮廓网格与默认参数核对 X 原始校准。两侧共 128 个顶点，在复位后与原形的最大差异小于 0.001 毫米。对于其他只保留了 220/221 倾斜轮廓的旧角色，可在 Body Setup & Recovery 中选择相应腿，使用 **Fit Neutral Sole** 绕静置脚踝找平，保留现有朝向；已丢失的历史朝向需要原始校准才能精确恢复。
