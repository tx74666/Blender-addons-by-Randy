# Character Designer 0.77.283 · 精简 Rig 面板

**Character Setup** 置于 Bone Display 上方，集中显示 Main Rig、Weight Mesh、Hips、Head，默认折叠。

Body Controls 使用一行 **Arms / Legs / Fingers** 切换。Arms 显示手臂范围和 Forearm Twist Correction，Legs 显示腿和脚范围，Fingers 显示手指工具。Back & Chest 和 Curve Chain Controls 在 Arms、Legs 下可用。

移除 Rig 页说明行、重复的 **Save Pose** 和 **Target Rotation** 面板。Animation 保留 Save Pose，现有 Alt+R 保留手腕与脚部重置逻辑。

54 项相关测试及隔离 Blender 5.2 验证通过。Blender 5.2 和 X 的插件副本各 326 个文件、0 差异。此版从已批准的 0.77.281 单独发布 Rig 改动，导出队列仍在验证。当前 X 会话未刷新。
