This avoids keeping a second imported character as the editing target. Source remains a linked library Action; Custom remains a local editable Action.

## Limits

Support is limited to the currently verified manual Dress structure. A non-null recorded Dress `physics` state is rejected because the shipped baseline lacks the corresponding complete physics ownership validator. Independently animated Dress locals, non-Rest constant Dress offsets, edited or unknown constraints / drivers, and changed control ownership are also rejected.

Direct use of an existing Rig still requires the packet's historical model path / hash to agree with the connected workspace and link record, plus strict matching against the actual artist Rig. The current production FBX has superseded that historical model; it does not establish the old packet's provenance. **Sync** continues to require a fresh matching model SHA and export. This release does not weaken that Sync requirement.
