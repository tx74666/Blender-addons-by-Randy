## 使用

1. 选中头发 Mesh，进入 Edit Mode，只选一侧的一整束头发或一个连续面区。
2. 打开 **Character Designer → Weight → Weight Symmetry**。
3. 点击 **Preview Replacement**：蓝色为不变的源区，绿色为镜像结果，灰色框为镜像平面，彩色编号为即将整块替换的目标。
4. 点击 **Mirror Selected Region**。唯一且可靠的目标会自动替换；有歧义时，在弹窗填入视口显示的目标编号，再确认。0 表示自动，不会绕过歧义检查。
5. 操作后仍选中源侧，可以继续修改源侧后再次镜像。Ctrl+Z / Ctrl+Shift+Z 为单步撤销/重做。

绑定与未绑定的网格使用同一个按钮。有权重时一起镜像，沿用现有骨架，不复制或改动骨骼。编辑模式不再显示另一套权重专用按钮或绑定区分文字；权重专用操作仍保留在 Pose / Weight Paint 等对应模式。

操作范围是当前同一个 Mesh。默认基准仍是该 Mesh **本地 X=0**，并非视图左右或顶部 Global，但不再把这行文字常驻在面板上。

正常使用不需要设置。特殊情况下可通过 **F3 → Mirror Settings** 指定参考平面和接缝容差；移除了 Shift-click 特殊行为和提示，没有常驻高级折叠栏：

- Symmetry Reference：为空时使用 Mesh Local X；指定 Empty 等对象时，使用其本地 X=0 在世界中定义的平面。参考对象无需是骨架。设置保存在场景中。
- Seam Tolerance：Mesh 本地单位；0 根据源区边长中位数的 10% 自动计算。只用于接缝匹配，不是对全头发执行 Merge by Distance。

## 安全边界

完整独立网格岛（包括封闭岛）按**一束对一束**匹配：整体删除旧目标的面、点和相连残边，再从源侧重建，不做逐点细补，也不会把两束邻近头发拼成一个目标。目标有洞或缺失指向末端的一段，不要求与源束拥有相同闭合状态、顶点数或面数。

局部选择由选中面区的边界 loop 决定范围；开口发片允许止于自身边缘的边界路径。找到对应边界后，只替换边界选定一侧内的区域，保留根部和外侧。不能用一条没有任何选中面的 loop 猜用户要的是哪一侧。中线可作为虚拟接缝，不自动切割跨两侧的面，也不焊接附近其他发束。

匹配使用按面积均匀的双向表面采样、截面宽度、沿长度的截面位置及偏差连续性，避免顶点密度和单个最远点主导结果。只有包围范围重叠的无关头发不会阻止操作；有明显胜出的可靠目标时自动整块替换。两个同样可信的候选、过少的表面证据或未识别的松散残片仍要求明确选择；不会为消除错误而随便删除多块。匹配分数不是统计概率。极端变形、跨中线或断成独立碎片的区域可能需要手动指定/重新选择。

源侧、其他面区和无关松散边点不改；只有已确认目标区域被替换，目标的连接缝按源侧镜像位置对齐。保持 UV（不翻 UV）、材质、平滑/锐边/接缝/折痕/倒角属性、支持的自定义属性、自定义法线、相对 Shape Keys 和权重。通用属性值按来源复制，不猜测向量属性的几何含义。

权重 .L/.R 对换；缺少对侧组时新建；无后缀组同名复制。不需要骨骼来证明这些组存在，也不自动归一化。锁定组若会改变则拒绝。

暂不支持：共享或链接 Mesh、非 Basis 编辑、锁定/绝对/动画/驱动 Shape Keys、使用侧别权重组蒙版的 Shape Key、顶点父子关系、Multires 雕刻层，以及 Hook/绑定变形/模拟等顶点索引依赖数据。遇到这些情况提示后停止。共享中线在某个 Shape Key 中偏离镜像平面时同样拒绝。启用的 Mirror 修改器必须由用户明确关闭视口和渲染开关，避免把已经生成的对侧再次生成；不会自动 Apply Modifier/Transform。

实现先构建临时 Mesh、复制并验证数据，然后切换原对象的数据块。写入或选择恢复失败会回滚。旧版拓扑 Copy/Repair API 保留兼容，界面不再让用户先猜该用哪个。

- 旧拓扑镜像 7 项、权重镜像 36 项、UI 路由 4 项回归保持通过。
