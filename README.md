# Character Designer

Blender 角色工具：建模、骨架、權重、頭髮與動畫編輯。

## [⬇ 下載 Character Designer 0.77.167](dist/character_designer-0.77.167.zip?raw=true)

安裝包約 **2 MB**，目前使用 **Blender 5.2** 驗證。

### 主要功能

- **建模與參考**：對稱編輯與修復、部件管理、參考視圖。
- **骨架控制**：身體設定、四肢 IK/FK、手腕與腳部控制。
- **手指工具**：骨鏈生成、關節對齊、鏡像與彎曲校準。
- **綁定與權重**：快速綁定、局部重算、對稱、補漏與清理。
- **頭髮與裙子**：髮束中心線、骨骼綁定、分段替換、裙子控制與物理預覽。
- **姿態編輯**：Rest Pose、姿態庫、鏡像、混合與偏移。
- **動畫編輯**：Source／Custom 版本、控制器編輯、整段位移與關鍵幀精簡。
- **Unity 聯動**：角色／動畫導出、動畫同步、預覽與回傳。
- **本地 AI 動作（選配）**：透過 Kimodo 生成動作。

### 安裝

1. 開啟 **Edit → Preferences → Add-ons → Install from Disk**，選取下載的 ZIP。
2. 啟用 **Character Designer**。
3. 在 3D 視窗按 **N**，開啟 **Character Designer** 分頁。

物理預覽需另裝 Wiggle 2；AI 動作需 Kimodo；Unity 聯動需配置隨包附帶的配套工具。基本工具可獨立使用。
