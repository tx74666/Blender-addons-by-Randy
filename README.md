# Character Designer

Character modeling, rigging, weights, hair and animation tools for Blender.

## [⬇ Download Character Designer 0.77.167](dist/character_designer-0.77.167.zip?raw=true)

About **2 MB**. Tested with **Blender 5.2**.

### Features

- **Modeling & references**: Symmetry editing and repair, part management and reference views.
- **Rig controls**: Body setup, limb IK/FK and wrist/foot controls.
- **Fingers**: Bone chains, joint alignment, mirroring and bend calibration.
- **Binding & weights**: Quick binding, local recalculation, mirroring, unweighted vertex repair and cleanup.
- **Hair & skirts**: Hair centerlines, bone binding, segment replacement, skirt controls and physics previews.
- **Poses**: Rest Pose, pose library, mirroring, blending and offsets.
- **Animation**: Source/Custom versions, controller editing, clip-wide movement and keyframe reduction.
- **Unity integration**: Character/animation export, animation sync, previews and round-trip updates.
- **Local AI motion (optional)**: Motion generation with Kimodo.

### Installation

1. Open **Edit → Preferences → Add-ons → Install from Disk** and select the downloaded ZIP.
2. Enable **Character Designer**.
3. In the 3D View, press **N** and open the **Character Designer** tab.

Physics previews require Wiggle 2; AI motion requires Kimodo; Unity integration requires the included companion tools to be configured. Core tools work independently.
