# Character Designer

Blender 角色工具：建模、骨架、權重、頭髮與動畫編輯。

## [⬇ 下載 Character Designer 0.77.167](dist/character_designer-0.77.167.zip?raw=true)

安裝包約 **2 MB**，目前使用 **Blender 5.2** 驗證。

### 安裝

1. 開啟 **Edit → Preferences → Add-ons → Install from Disk**，選取下載的 ZIP。
2. 啟用 **Character Designer**。
3. 在 3D 視窗按 **N**，開啟 **Character Designer** 分頁。

物理預覽另需 Wiggle 2；建模、骨架與權重等基本工具可獨立使用。
